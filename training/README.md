# 小黑貓培訓資料來源

`nhi-dentist-handbook-2026.json` 是使用者提供的《2026 牙醫師實用手冊 I：健保事務內容》之逐頁文字索引，與 `files/nhi-dentist-handbook-2026.pdf` 對應。

- `pdf_page` 使用 PDF 閱讀器的 1 起算頁碼；書內印刷頁碼約比它少 1 頁。
- `sections` 依原書目錄整理；`pages[].text` 由 PDF 文字層擷取。空白或圖片頁可能沒有可擷取文字，查證時仍須看原 PDF。
- 此檔僅供日後建立可追溯來源的規範問答，不是已審核的判定規則，也未接入小黑貓自動回答。
- 產生對外答案前，應核對原 PDF 頁面、適用年度及健保署現行公告；涉及個案條件、醫師資格、申報週期或不得併報項目時不可只憑關鍵字判定。
