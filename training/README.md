# 小黑貓培訓資料來源

`nhi-dentist-handbook-2026.json` 是使用者提供的《2026 牙醫師實用手冊 I：健保事務內容》支付標準相關原頁的逐頁文字索引，與 `files/nhi-dental-payment-standards-2026.pdf` 對應；完整原書未放入現行網站。

- `pdf_page` 是 56 頁摘錄的閱讀器頁碼；`source_pdf_page` 是原 154 頁 PDF 的頁碼。原頁範圍為 3–8、10–13、19–56、63–70。
- `sections` 依摘錄內容整理；`pages[].text` 由 PDF 文字層擷取。空白或圖片頁可能沒有可擷取文字，查證時仍須看摘錄 PDF 與現行公告。
- 此檔僅供可追溯地定位原頁，不是已審核的判定規則；小黑貓只提供候選代碼與摘錄頁供使用者確認，不自動判定可否申報。
- 產生對外答案前，應核對原 PDF 頁面、適用年度及健保署現行公告；涉及個案條件、醫師資格、申報週期或不得併報項目時不可只憑關鍵字判定。
