# 樂衍小黑貓（桌面版）

在 Windows 桌面走動的小動物。點一下打開問答視窗（`cat.html`），右鍵可以餵零食、玩逗貓棒、換夥伴。

夥伴跟網站同步：在問答視窗換夥伴，桌面那隻也會跟著換（靠視窗標題「樂衍＋夥伴名字」判斷）；在桌面右鍵「換夥伴」，下次打開問答視窗會帶 `?pet=` 用同一隻。選擇存在 `%APPDATA%LeyanCatpet.txt`。小黑貓用程式畫，小貴賓、小白兔、小熊、小倉鼠用網站同一套圖（PNG 內嵌在 `LeyanCat.ps1` 的 `$petImages`）。

| 檔案 | 說明 |
|---|---|
| `LeyanCat.ps1` | 小黑貓本體（PowerShell 5.1 + 內嵌 C#，用 `Add-Type` 編譯）。**存檔要 UTF-8 含 BOM、CRLF 換行**，否則中文會變亂碼 |
| `啟動小黑貓.bat` | 啟動檔（Big5/cp950 編碼）。內容只有一行，用 `%~dp0` 找同資料夾的 `LeyanCat.ps1` |

## 修改時注意

- 內嵌的 C# 只能用 **C# 5** 語法（Windows 內建編譯器）：不能用 `$"..."` 字串插值、`=>` 屬性、`?.`、`nameof`。
- 錯誤會寫到同資料夾的 `LeyanCat-error.log`。
- 改完無法在 Linux／NAS 上測試，要在 Windows 上雙擊 `啟動小黑貓.bat` 實測；新版啟動時會自動請舊的那隻結束。
- 發給其他電腦：把這兩個檔案（加一份安裝說明）壓成 zip。
